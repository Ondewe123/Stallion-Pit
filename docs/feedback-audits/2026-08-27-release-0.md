## Reusable Audit Procedures

### Feedback edit

1. Create a report named `[AUDIT TEST] Feedback edit` in production and record its exact full ID.
2. Edit its type and comment, then restore its original type and comment.
3. Confirm the exact ID again, then delete only that test report.

### Fuel deletion

1. Create a dedicated temporary vehicle named `[AUDIT TEST] Fuel chain` and record its exact ID.
2. Add fuel rows at odometers 1000, 1100, and 1250, recording each exact row ID.
3. Delete only the 1100 test row; the 1250 row must show 250 km since the preceding row.
4. Confirm the exact IDs, then remove the three test rows and the temporary vehicle.

### Fuel long gap

1. On `[AUDIT TEST] Fuel chain`, add dated rows more than 180 days apart and record their exact IDs.
2. Exclude the boundary row from the economy chain.
3. Expect a gap hint and a null per-fill value after the exclusion, then remove only the recorded test rows.

### Route map

1. On Routes, calculate Nairobi CBD → Naivasha.
2. Expect a visible polyline, A/B markers, distance, duration, and a vehicle-cost table.
3. If it fails, record the exact actionable error text shown to the user.

### IPC completeness

1. Record database diagram and part counts for the active vehicle.
2. Clear every UI filter and compare the rendered options with those counts.
3. Inspect the three reported diagram/snag cases and record selected diagram IDs and visible results.

### Part image

1. Paste a supported supplier URL into Parts add/edit and verify image retrieval.
2. Separately verify whether direct local-file upload is absent or present.

### Maintenance readiness

1. Verify existing work-order target-date and planned-parts features.
2. Record which shopping-list and readiness requirements remain absent.

Temporary-record cleanup is authorized only for records created by these procedures. Resolve and record exact IDs before deletion; never use broad filters or recursive filesystem/database operations.
